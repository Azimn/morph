# MORPH-002: matched event order and persistence

Status: exploratory protocol frozen before executing the new assay. This is not an externally registered confirmatory study. It follows MORPH-001's environment-contingent differentiation assay and does not redefine that result as within-environment path dependence.

## Inherited lessons

Vivarium's frozen neutral adult battery and no-plasticity control motivate an identical terminal task battery and growth-disabled controls. Kurzweil v0.5's dominant mature reconvergence motivates multiple continuation horizons. Its v0.6 protocol motivates atomic event swaps that preserve the exact event multiset and resource opportunities. Pretorius 001F/001G motivate measuring functional outcomes rather than state change alone. Bicentennial Man's founder characterization motivates equal-age probes and byte-identical history replicates.

## Frozen design

Use the unmodified v0.1.0 six-template genome, threshold and cost metadata. One seed ID and initial state per paired developmental comparison. Thirty developmental turns share the same resource credits, absolute times, task contents, and event multiset. Two observed retrieval-loss events each carry 1.4 synthetic units, totaling 2.8, which exceeds the inherited 2.5 memory threshold. In EARLY they occur at turns 1 and 2. In LATE the same complete event objects swap with neutral events at turns 17 and 18. No payload is rewritten, duplicated, or sorted by its original age during execution. The external observation IDs stay with their events.

Run a pruning-only case with no memory acquisition or maintenance queries. Run a retained-memory case with eight distinct exact-key records at turns 3 through 10 and identical anchor queries at turns 14 and 24. These queries give no missing answer to the subject. The early arm can store those records, whereas late growth cannot reconstruct vanished inputs. These dates intentionally straddle the availability boundary and are authored to exercise it. This is a favorable mechanism test, not a discovered ecological niche or independent task benchmark.

## Controls

The developmental condition starts empty with growth enabled. Its growth-disabled control starts empty and never mounts a structure. Its fixed-memory control explicitly allocates the inherited episodic organ at turn zero and charges the inherited compilation cost. This allocation is a named experimental control, never a claim about the zygote boot contract. Fixed control maintenance and atrophy rules stay active. Compare EARLY and LATE within each condition; cross-condition costs are reported, not described as compute matched.

Run each identical history a second time and require exact endpoint and output reproduction. From each endpoint, continue under exactly identical input for 64 turns. In pruning-only continuation, all turns are neutral. In retained-memory continuation, every eighth turn queries the same anchor without re-presenting its content. Capture at continuation ages 0, 8, 32, and 64. The retained-memory case tests persistence under continued attempted use, not survival through total inactivity.

## Evaluation and causal intervention

At every capture, run the same eight exact-key recall questions on independent deep copies, each question at the same age and clock. Evaluation must leave the original state byte-identical. Score exact returned source value, not phrasing. Record live organ IDs and content-state hashes separately from genesis dates and audit hashes; different receipt dates alone do not count as functional or structural divergence. Preserve all native outputs, resource reserves, lifecycle events, input traces, and matching hashes.

Repeat each battery with the episodic organ deleted from evaluation copies. Log that ablation only on the copy. It removes both stored content and processing capacity, so it can establish joint necessity for this recall difference, not isolate a particular learned weight or structural detail. Sham evaluation uses the same copy-and-step process without deletion.

## Gates and interpretation

The developmental pair must have the same boot-state hash. Every condition's EARLY and LATE event multisets, task payloads, total pressure, time schedule, and credited resource opportunities must match exactly. Execution order must demonstrably differ. Every identical-history repeat must reproduce. Evaluation must be nonmutating. Any failure invalidates the affected comparison.

Different endpoint topologies with identical recall scores are structural timing effects without a functional advantage. If common neutral continuation removes that difference, report reconvergence. Persistent recall differences with identical topology support timing-dependent acquisition inside the authored developmental system. If removing the organ eliminates that gap, report causal dependence on the memory mechanism. If fixed-memory controls show the same order gap, the growth-specific explanation fails. Growth-disabled controls test whether a hidden kernel history store explains recall.

Do not require divergence to pass tests, tune thresholds after viewing outcomes, infer irreversible architectural incompatibility, or claim a developmental superiority result from the favorable acquisition window.
