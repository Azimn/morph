# Audit of the supplied reference proposal

The source for this implementation is Jay's M.O.R.P.H. specification supplied in this conversation on October 14, 2026, America/Chicago. It describes six pressure-triggered organs, a zero-organ zygote, developmental receipts, pruning, and three divergent histories. This document records the engineering corrections so the implementation can be compared to that proposal without treating aspirational language as an observed result.

The proposed GENOME_REGISTRY references all six concrete classes at module scope. An empty mounted dictionary does not establish interpreter-level lazy loading. This implementation puts metadata in an external JSON catalog and tests sys.modules in a fresh process before any organ grows.

The proposal allows dormant genome templates while banning dormant runtime modules. That is coherent only if the boundary is explicit: on-disk templates are allowed, live organ instances are absent, and template metadata is available to the engine. It is conditional instantiation from a pre-authored genome. Divergent mounted sets do not by themselves defeat the blueprint-with-extra-steps objection.

The proposed MSV contains persistent friction events, genesis records, and stopping certificates, despite describing the scratchpad as current-turn-only. Here, persistent instrumentation lives in an engineer-only audit object, the scratchpad is replaced every turn, and only bounded gradient/trigger bookkeeping remains in the kernel. Genesis cannot reconstruct lost conversational content.

The proposed maintenance comparison is actually a fixed cumulative threshold. It does not estimate benefit minus cost or prevent growth at zero reserve. This implementation charges compilation, reserves one maintenance unit of affordability, prunes unaffordable organs, and describes the remaining fixed thresholds as priors. Learned lifetime return on investment remains unimplemented.

The proposed hash covers only a few fields and is truncated. It is not a cryptographic signature and cannot prove authenticity. Here a full SHA-256 chain covers whole events, while documentation retains the distinction between integrity checking and authentication. Lifecycle history is append-only by API, including atrophy and rebirth.

The supplied renderer labels a deterministic formatter as an NLI gate and changes only a style prefix when a purported model ID changes. No actual model is substituted. Here formatting substitution is tested and reported as such, with no model IDs or NLI claim. Raw numerical and structural state remains in the separate engineer channel, preserving the first-person subject boundary.

The proposed spontaneous-resolution strings neither solve anomalies nor run autonomously. Its staging loop can also perform work after its authorized budget is exhausted. Here a budgeted, persisted deadline queue emits due events through caller-driven ticks, with explicit costs and idempotency. No unobserved background thinking or task completion is claimed.

The proposed memory code applies an asymmetric exponential update, not a Kalman filter, and its sample trajectories do not match the initialized domains. Here exact outputs come from executed tests, separate domains start at the same neutral estimate, and documentation calls the update what it is. Path dependence in policy values does not establish irreversibly different software schemas.

The proposed procedural cortex compiles after a single trigger event or three later repetitions, despite a five-repetition requirement, and stores no executable steps. Here five verified repetitions after organ birth are required and macros execute a small allowlisted pure-action language. Its reduced planning count is a symbolic measure, not real token savings.

The proposed arbiter chooses the highest-ranked K tasks without enforcing their combined cost, and marks itself used on every call, making inactivity pruning impossible. The proposed audit mirror has the same always-used problem. Here actual relevant work updates usage and selection enforces a cumulative task budget.

The proposal's global cultural norms may cross partner boundaries. Here norms and callbacks are partner-scoped. This is basic record isolation, not demonstrated general theory of mind or cultural cognition.

Only four Article probe flags appear in the proposed kernel, while the text claims 34 Article checks. Here all numbered prerequisites are mapped, but none claims Article support without the missing source protocols and independent evidence. Failing a runnable unit test is distinct from failing an Article; missing an organ is distinct from implementing a capability and failing its evidence test.

The proposed exact birth sessions and topology names are illustrative, not reproduced measurements. This release records actual turn-level births under its synthetic histories. It does not require the three organ sets to be disjoint, require particular personality labels, or report unmeasured biological properties.
